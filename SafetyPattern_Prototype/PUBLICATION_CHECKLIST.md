## 文件冻结

默认校验不会写文件：

```powershell
python -B tools/verify_archive.py
```

补入模型/图片或修改说明后，显式更新本发布包的文件校验表，再校验：

```powershell
python -B tools/verify_archive.py --write-checksums
python -B tools/verify_archive.py
```

源文件对应清单仍用于核对原型和保存结果，不能通过更新校验表掩盖修改过的原型代码或实验记录。模型和图片未提供历史源指纹时，应如实登记新增材料。

Git不跟踪真正的空目录；ZIP会保留两个空目录。填入文件后再加入Git，不把空目录解释为原始模型已经归档。
